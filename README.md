# SlackBot: The Basics
This is a SlackBot I created for Stardance (a Hack Club YSWS event), using a guide that was provided on the Stardance website!

The Slack Bot has multiple features, all of which were designed to be after an animal! Each cute animal will run a different feature!

# Commands
There is:
/normalsidekick-ping - just saying hi!
/normalsidekick-help - ʕ/ •ᴥ• /ʔ bear give you all commands when needed
/normalsidekick-joke - @'-' snail will crack you up, 
/normalsidekick-randofact - get a random fact, courtesy of kitty (^..^)=~
/normalsidekick-mousy - <:3~~~~ mousy wants to say hi to you!

You can run any one of these on the Hack Club Slack! (link provided on the actual demo link)
